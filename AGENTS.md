# Agent Context

## Design Context

This project has committed design documentation at the repo root:

- **[PRODUCT.md](PRODUCT.md)** — register (product), target users, brand personality ("Confident and professional, warm and encouraging, direct and efficient"), anti-references, strategic design principles.
- **[DESIGN.md](DESIGN.md)** — visual system: "The Career Atelier" (deep-brown ink + single emerald accent on warm cream, Newsreader serif + Manrope sans, flat-by-default elevation). Read this before styling or adding any UI.
- **`.impeccable/design.json`** — machine-readable sidecar (tonal ramps, component HTML/CSS snippets) consumed by `$impeccable live` variant mode.

Any UI work (new views, components, redesigns) should read DESIGN.md first and follow its Do's and Don'ts, not invent a new visual language.
